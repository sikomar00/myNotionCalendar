- 기기 확인은 최종 코드를 `adb install -r`(데이터 유지)로 덮어 설치해 진행했다. 바꾼 기기 설정(시스템 글꼴 배율, 비행기 모드)은 모두 원래 값(0.8, 0)으로 복구했고, 테스트로 놓은 위젯 2개와 `AllTodos` 등록을 지웠다. 앱 위젯은 처음과 같은 2개(달력 + 일정, 통합 탭)다.
- 자동화 중 홈 편집 모드의 `+`(페이지 추가) 타일을 잘못 탭해 빈 홈 페이지가 생겼고, 화면과 격자 요소가 0임을 확인한 빈 페이지만 지워 홈을 처음과 같은 2페이지로 되돌렸다. 다음에 같은 자동화를 한다면 편집 모드에서 못 찾았을 때 탭하지 않도록 한다.
- 위젯 선택기는 `adb input text`가 한글을 못 쳐서 검색 대신 앱 목록을 스크롤해 찾았다.
