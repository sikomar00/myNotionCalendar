# 위젯 디자인 점검표 (2026-11-03)

위젯 9종의 화면과 코드를 구글 공식 [위젯 품질 기준](https://developer.android.com/design/ui/mobile/guides/widgets/widget_quality_guide)·[표준 레이아웃](https://developer.android.com/design/ui/mobile/guides/widgets/layouts)에 대어 본 결과다.
근거는 `docs/shots`의 2026-10-16~21 촬영본(이후 바뀐 화면은 못 봄)과 코드 인벤토리다. **실기기 재촬영은 하지 못했다(폰 미연결, 미검증).**
개선 방향은 `docs/plans`가 아니라 세션 계획(과감한 새 스타일, 공통 부품 먼저 + 3종)을 따르고, 시안은 승인 뒤 `DESIGN.md` '위젯' 절로 확정한다.

## 2. 고칠 결함 (스타일과 무관)

1. 눌림 영역 48dp 미달. 보이는 크기는 작아도 눌림 영역만 48dp로 늘리는 공통 규칙이 없다.
2. 디데이 목록의 머리(13sp)·빈 상태(11/12sp)가 글꼴 상한(1.3배)을 우회해 큰 글꼴에서 잘릴 수 있다(`DdayWidget.kt:180,259,277`).
3. 상태가 색만이다(동기화 실패 ●, 휴일=일요일 빨강, 습관 잔디 3단계 투명도).
4. 월간 제목의 `contentDescription`이 눈에 보이는 월 글자를 대신한다.
5. 분할 위젯의 파란 `+`가 일정 목록 마지막 줄을 덮는다(`SplitWidget.kt:428-452`).
6. 탭형: 머리가 두 줄, 이모지 탭 라벨, 설정이 습관·가계부 탭에는 적용되지 않는데 화면에는 같이 나온다.
7. 위젯 설정 화면: 미리보기가 스크롤되어 사라짐, 줄 수 칩이 넘칠 수 있음, 초기화 없음, 습관은 설정 화면 자체가 없음.
8. 노션 보기: 새로고침 반응 없음, 빈 상태에 '새 항목' 버튼 없음, ☐·☑ 글리프가 폰트 의존, 목록 행 32dp.
9. 오늘 표시 5종, 날짜 형식 6종, 일정 점 모양 2종이 위젯마다 다르다.
