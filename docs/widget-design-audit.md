# 위젯 디자인 점검표 (2026-11-03)

위젯 9종의 화면과 코드를 구글 공식 [위젯 품질 기준](https://developer.android.com/design/ui/mobile/guides/widgets/widget_quality_guide)·[표준 레이아웃](https://developer.android.com/design/ui/mobile/guides/widgets/layouts)에 대어 본 결과다.
근거는 `docs/shots`의 2026-10-16~21 촬영본(이후 바뀐 화면은 못 봄)과 코드 인벤토리다. **실기기 재촬영은 하지 못했다(폰 미연결, 미검증).**
개선 방향은 `docs/plans`가 아니라 세션 계획(과감한 새 스타일, 공통 부품 먼저 + 3종)을 따르고, 시안은 승인 뒤 `DESIGN.md` '위젯' 절로 확정한다.

## 2. 고칠 결함 (스타일과 무관)

1. 눌림 영역 48dp 미달. 보이는 크기는 작아도 눌림 영역만 48dp로 늘리는 공통 규칙이 없다.
2. 디데이 목록의 머리(13sp)·빈 상태(11/12sp)가 글꼴 상한(1.3배)을 우회해 큰 글꼴에서 잘릴 수 있다(`DdayWidget.kt:180,259,277`).
3. 상태가 색만이다(동기화 실패 ●, 휴일=일요일 빨강, 습관 잔디 3단계 투명도).
4. 월간 제목의 `contentDescription`이 눈에 보이는 월 글자를 대신한다.
5. 분할 위젯의 파란 `+`가 일정 목록 마지막 줄을 덮는다(`SplitWidget.kt:428-452`).
6. 탭형: 머리가 두 줄, 이모지 탭 라벨, 설정이 습관·가계부 탭에는 적용되지 않는데 화면에는 같이 나온다.
7. 위젯 설정 화면: 미리보기가 스크롤되어 사라짐, 줄 수 칩이 넘칠 수 있음, 초기화 없음, 습관은 설정 화면 자체가 없음.
8. 노션 보기: 새로고침 반응 없음, 빈 상태에 '새 항목' 버튼 없음, ☐·☑ 글리프가 폰트 의존, 목록 행 32dp.
9. 오늘 표시 5종, 날짜 형식 6종, 일정 점 모양 2종이 위젯마다 다르다.

## 5. 실기기 점검 기록 (2026-11-03, Galaxy S25 SM-S931N, 디버그 빌드 설치)

본 점검은 폰이 연결된 뒤 처음 한 것이다. 개인 일정이 보여 화면 캡처는 저장소에 올리지 않았다(임시 폴더에만 둠).

**확인함**
- 새 스타일이 실제로 둥글게 나온다: 원형 톤 버튼·채운 `+`, 주 타일 모서리, 타일 행, 원형 체크. 시험 환경(Robolectric)은 모서리 반경을 그리지 않아 이것만은 기기에서만 확인할 수 있었다.
- 월간(탭형 안 '일정' 탭): 주 타일 사이 1dp 틈, 일정 5줄 + `+N`이 이전과 같은 배치, 오늘 날짜 알약, 머리(연월·동기화 시각·날씨 칩·버튼 4개).
- 습관(탭형 안 '습관' 탭, 4×7): 이름 타일 행, 원형 체크(한 날은 초록 채움), 오늘 열 굵게.
- 노션 보기 2×2(Reading)·4×5(Monthly): 아이콘 칩, 제목, 부제 '완료 30/50', 새로고침·`+` 버튼, 행 타일, 원형 체크, 열 머리.
- 시스템 글꼴 0.8과 2.0(위젯 글자는 상한 1.3배): 월간·노션 보기 모두 잘림·겹침 없음. 1.0도 캡처했으나 눈으로 보지 않았다.
- `adb logcat -d -s NotionCalStrictMode:W` 0줄, 위젯 관련 크래시·예외 없음.
- 삼성 런처는 위젯 크기를 약 1.4배로 보고한다(`hsResizeRatio` 0.714). 그래서 dp 값이 화면에서는 0.714배로 그려진다(행 34dp → 눈에 27dp). 눌림 48dp 기준을 늘리지 않고 밀도를 우선한 결정을 지지한다.

**고침**: 습관 '이번 주 n/목표' 글자가 타일 오른쪽 끝에 붙던 것(여백 6dp), 노션 보기 표의 체크 열 머리 글자가 원형 체크와 어긋나던 것.

**확인하지 못함(미검증)**: 습관 단독 위젯·월간 단독 위젯(홈에 놓여 있지 않다), 라이트 모드·낮은 투명도·Material You, TalkBack 낭독, 글꼴 1.0 화면, 상태 알약·날짜 알약(이 보기들에는 상태·날짜 열이 없다), 오류·오래됨 줄, 빈 보기, 위젯 탭으로 체크·새 항목 동작(M4).
**알게 된 것(이번 변경 아님)**: 탭형 '습관' 탭 위쪽 이번 달 잔디(요일 줄 + 막대)와 목록 사이에 빈 공간이 크다.
