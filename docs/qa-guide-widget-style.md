## 4. 열린 문제

- 탭형 위젯 '습관' 탭 위쪽 이번 달 잔디와 목록 사이에 빈 공간이 크다(이전부터 있던 것, 미래 날짜 칸을 비워 두는 HB-03 정의 때문).
- 습관·노션 보기 행은 눌림 높이 48dp 대신 한 화면에 보이는 개수(밀도)를 우선했다(사용자 결정). 눌림 폭은 48dp.
- 표지 내려받기 실패는 로그에 남기지 않는다(꾸밈이라 조용히 건너뛰고 6시간 뒤 다시 시도). 표지가 안 나오면 UW-01의 순서(새로고침 → 10~20초)를 먼저 확인한다.
- 인자 3개 이하 규칙을 어긴 부품 함수가 있다(`WidgetHeader` 등, 코드 리뷰 지적, 호출부 전체를 건드려야 해서 보류).
- M5b(진행 막대 옆 `−`/`+`로 읽은 쪽수 바꾸기)와 PRD v2 정렬 확정 3건은 아직 시작하지 않았다.

## 5. 실행 메모

- 실기기 점검은 디버그 빌드를 덮어 설치해 했고(데이터 유지), 시스템 글꼴 2.0·라이트 모드는 잠시 바꿨다가 원래 값(0.8, 다크)으로 되돌렸다.
- 체크 탭 확인은 노션의 실제 행 하나를 체크했다가 해제했다(순 변화 없음).
- 책 위젯은 2026-11-03 오후 기기에 놓아 확인했다(UW-01·03·05). 위젯 놓기·설정 저장은 홈 화면을 직접 조작해 했다(빈 자리에 위젯 하나 추가됨). 오프라인 유지(UW-02)와 크기별 모양(UW-04)은 아직이다.
