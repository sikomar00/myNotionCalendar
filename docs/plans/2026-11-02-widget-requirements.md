# 위젯 요구사항 정리 (2026-11-02)

노션 DB를 습관·캘린더 앱처럼 **탭으로 다루는 홈 위젯**으로 만든다는 목표를 DB 5개 기준으로 풀어 쓴 문서다.
2026-11-02 사용자 인터뷰(구글 캘린더 모양 요청 + 사용자가 직접 고친 Q1~Q5)를 합쳤고, 겹치는 곳은 **사용자가 고친 글이 우선**이다.
구현 순서와 근거는 마일스톤 M0~M6(아래 §3)이고, 마일스톤마다 따로 승인받아 진행한다.

참고 이미지(`Refs/`, 개인 일정·프로필 사진이 있어 커밋하지 않는다): `gglCal.png`(구글 캘린더 월), `bankSalad.png`(뱅크샐러드 가계부), `밀리의서재위젯.png`(밀리의서재 책 위젯).

## 1. 결정

| 영역 | 결정 |
|---|---|
| 대상 DB 5개 | 📅 Calendar / 할 일(AllTodos) / 습관 / 💰 가계부 / Reading. 새 DB는 같은 틀로 늘린다 |
| 캘린더 일정 표시 | **수정하지 않는다**(점+글자, ✓ 취소선, 여러 날 막대) |
| 캘린더 완료할 일 | **수정하지 않는다** |
| 캘린더 주차 | 설정에서 켜고 끈다, **기본 끔**. 켜면 주 시작 요일 설정을 따르고 1월 1일이 든 주가 1주(일요일 시작이면 2026-11-01 주=45주) |
| 캘린더 음력 | 하지 않는다 |
| 캘린더 모양 | 둥근 날짜 타일, 상단바(☰ 서랍·`11월▾`·검색·오늘 아이콘), 파란 `+` 버튼 |
| 캘린더 이동 | 1단계는 모양, 2단계는 세로 스크롤 |
| 할 일 | 체크, 상태 바꾸기, 날짜 지정. 날짜는 **새 항목 추가 시트의 날짜 칸**에서 정하고, 이미 있는 항목은 앱에서 바꾼다 |
| 습관 | 오늘 체크, 연속 일수(지금 그대로) |
| 가계부 | 한 줄 입력, 이번 주 남은 돈. **UI는 뱅크샐러드를 참고** |
| Reading | 읽는 중 책 갤러리. **UI는 밀리의서재 위젯을 참고**. 책 표지 이미지를 허용한다 |
| 틀 | 노션 보기 종류별 틀 + 용도(습관·가계부 …)는 그 위의 "레시피" |
| 위젯 탭 | 필수 4가지: 체크 토글 / 상태·선택 바꾸기 / 숫자 ± / 새 항목 추가(시트). 날짜 미루기·삭제·본문 편집은 **앱에서** |
| 유지 | 개인용(토큰 하나, 서버 없음, 스토어 배포 안 함), 앱은 설정·편집 시트·'더 보기'만, DB 하나 1,000행 이하, 습관·가계부 전용 구현은 유지하고 새 범용 경로는 따로 만든다 |
| 반영 시점 | 앱·시트를 열 때 + 위젯 새로고침 + **주기 동기화 30분**. 폰에서 한 수정은 즉시 |
| 하지 않는 것 | 노션 버튼 속성 대체("동작 버튼"), 음력, 구글 프로필·할 일 아이콘, 가계부 목록/달력 토글·필터·검색·분석 카드, 위젯에서 날짜 미루기·삭제·본문 편집 |
| 완료 기준 | 노션에서 DB나 보기를 새로 만들고, 앱에서 2분 안에 위젯으로 놓고, 위젯에서 탭만으로 체크·상태·숫자·추가가 10초 안에 노션에 반영된다. 달력 보기는 월 그리드, 보드 보기는 열이 나란히 나온다 |

## 2. 확인한 사실과 확인하지 못한 것

- 앱 월 화면에는 새 일정 `+` 버튼이 없고, 빠른 시트 `QuickSheetStart.Add(date)`는 이미 있다.
- `view_rows`는 표시 글자만 저장한다. 위젯에서 노션으로 쓰려면 속성 ID·종류·선택지 ID가 필요하다(M3).
- 쓰기 큐는 날짜 속성이 있는 캘린더형 DB가 아니면 작업을 버린다(M3에서 고친다).
- 위젯 비트맵은 PF-07과 `WidgetNoBitmapTest`가 막고 있다. 책 표지는 이 규칙을 바꿔야 한다(M5).
- 노션이 호스팅하는 표지 URL은 1시간 뒤 만료되므로 동기화 때 내려받아야 한다.
- **확인하지 못했다**: `Reading` 보기의 종류·표지 속성·진행 속성, 라이트 모드 모양, Android 17에서 위젯 진행 막대, 뱅크샐러드 분홍 점의 뜻(무지출 점은 우리가 정의한다).
