## API 근거 (PRD §API에 출처와 함께 적는다)
- Views API(2026-03-11): `GET /v1/views?data_source_id`(id만) → `GET /v1/views/{id}`(type·filter·sorts·configuration). `POST /v1/views/{id}/queries` = 보기의 필터·정렬대로 **페이지 ID만** 반환, 100개씩, 15분 만료, 최대 1만 건.
- 템플릿: `GET /v1/data_sources/{id}/templates`, `POST /v1/pages`의 `template`(default/template_id). 적용은 비동기, `children`과 같이 못 씀, `properties`는 함께 가능.
- 쓰기 가능: title·rich_text·number·select·multi_select·status(기존 옵션만)·date·people·files·checkbox·url·email·phone·relation·place(lat/lon). 읽기 전용: formula·rollup·created/edited time·by·unique_id·button.
- 제한: relation·people·mention은 페이지 응답에서 25개까지(property item으로 페이지네이션). 노션 파일 URL은 만료됨. 파일 업로드 단일 20MB(무료 워크스페이스 5MiB), 업로드 후 1시간 안에 연결.
- 본문 덧붙이기: `PATCH /v1/blocks/{id}/children`, 요청당 100블록, `position: end`.
- 웹훅은 공개 HTTPS 서버가 필요 → 범위 밖(개인용·서버 없음).
