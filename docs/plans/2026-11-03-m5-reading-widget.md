# M5 설계: Reading 책 위젯 (표지 갤러리 + 진행 막대)

상태: **승인됨(2026-11-03)**: PF-07 좁은 예외 허용, 토큰 없는 직접 내려받기, M5a(읽기)만 먼저. M5b(쓰기)는 M5a를 기기에서 확인한 뒤 승인받아 같은 날 구현했다(§4). 근거: `docs/plans/2026-11-02-widget-requirements.md`(Reading 항목, M5), PRD VW-09·PF-07, 참고 이미지(밀리의서재 위젯, 저장소 밖).

## 1. 목표

노션 `Books` 같은 DB의 '읽는 중' 보기를 **책 표지 + 읽은 비율 막대**로 보여 주는 위젯. 참고 모양: 어두운 둥근 카드 가운데에 표지와 가는 진행 막대, 오른쪽 위에 새로고침. 책이 여럿이면 표지를 나란히(2열, 4×4는 최대 6권). 표지를 누르면 그 노션 페이지, 막대 영역을 누르면 새로고침.

## 2. 실제 데이터에서 확인한 것 (읽기 전용으로 조회, 2026-11-03)

- `Books` DB: `cover`(**파일 속성**), `Status`(To Read·Reading·Read·Paused), `ing`(숫자), `page`(숫자, 전체 쪽), `진행률`(수식), `Title`, `Author`.
- 표본 행의 `cover`는 **외부 주소**(서점 이미지 서버, 만료 없음)였다. 노션에 올린 파일이면 주소가 1시간 뒤 만료된다 → 둘 다 다뤄야 한다.
- 지금 앱은 파일 속성을 `n개`라는 글자로만 읽는다(`PropertyDisplay`, VW-02). 주소는 버린다.
- **Reading 보기에는 제목 열만 보인다**: `ing`·`page`·`진행률`은 보기에서 숨겨진 속성이라 표시용 글자(`cells`)에 없다. 그래서 표지 주소와 읽은 비율은 행의 속성 JSON(숨긴 속성도 들어 있다)에서 동기화 때 직접 읽어 `view_rows.coverUrl`·`progress`에 둔다(설정에서 열을 고르는 방식은 쓰지 않는다).
- 위젯은 비트맵 금지(PF-07, `WidgetNoBitmapTest`). 이유: Android 17이 위젯 비트맵을 '화면 폭×높이×4바이트×1.5'로 제한하고 넘기면 앱을 죽인다.

## 3. 설계

### 3.1 데이터 (`:core:notion`, `:core:data`)
- `ViewReader`가 파일 속성의 **첫 파일 주소와 만료 여부**(external/file)를 읽어 `view_rows.coverUrl`에 둔다(Room v15, AutoMigration, 기본값 빈 글자). 표시용 글자(`cells`)는 그대로.
- `ViewColumn`에 종류 `files`를 알린다(`columnInfo`). 위젯이 '표지 열'을 알 수 있다.

### 3.2 내려받기·저장 (`:core:sync`만 네트워크)
- `ViewSync` 끝에서 `CoverDownloader`가 표지를 받는다. **노션 토큰을 보내지 않는 별도 OkHttp 클라이언트**를 쓴다(제3자 서버에 토큰이 새면 안 된다, 불변 규칙).
- https만, 응답 2MB 상한, 시간 제한 10초, 리다이렉트 3회, 이미지 형식만. 실패하면 이전 파일을 지우지 않는다.
- 받은 이미지는 **240×360px 이내로 줄여 JPEG(품질 80)** 로 `filesDir/covers/<pageId>-<주소 해시>.jpg`에 둔다(보통 20~40KB). 주소가 바뀌면 새로 받고 옛 파일은 지운다. 보기에서 빠진 책의 파일은 정리한다. 합계 상한 8MB(넘으면 오래된 것부터 삭제).
- 만료 주소(노션 업로드)는 동기화 때마다 다시 받는다. 외부 주소는 주소가 같으면 다시 받지 않는다.
- `:core:data`의 `CoverStore`(파일 읽기·쓰기·정리, 네트워크 없음)가 위젯과 동기화의 경계다.

### 3.3 위젯 (`:widget`)
- (구현 변경) 표지 열·진행 열은 설정에서 고르지 않고 자동으로 정한다. 표지: 이름에 cover·표지·image가 든 파일 속성, 없으면 첫 파일 속성. 진행: 이름에 진행·progress·%가 든 숫자·수식, 없으면 `ing`÷`page`.
- 새 위젯 `BookWidget`(선택 화면 이름 '책 갤러리'). `ViewWidget`과 같은 보기 등록·선택 화면을 쓰되 모양이 다르므로 제공자를 따로 둔다(표 위젯은 건드리지 않는다).
- 모양: 둥근 타일 카드(새 스타일 부품), 표지 + 가는 진행 막대 + 제목(한 줄). 표지가 없으면 제목 글자 타일. 책 수에 맞춰 열 수(1~3)를 정하고 4×2는 한 줄, 4×4는 두 줄.
- **진행**: 설정에서 '진행 열'을 고른다. 기본은 자동: 숫자·수식 열 중 이름에 `진행`·`progress`·`%`가 든 것, 없으면 열 이름 `ing`÷`page` 쌍. 값이 0~1이면 비율, 1 초과면 퍼센트로 본다. 계산할 수 없으면 막대를 그리지 않는다.
- 위젯은 Room과 `CoverStore`의 파일만 읽는다(WG-02). 파일 읽기·디코딩은 `provideGlance` 안의 IO에서 하고, 디코딩 결과는 위젯에 보이는 크기로 한 번 더 줄인다.

### 3.4 PF-07 좁은 예외 (사용자 승인 필요)
- 비트맵 API를 **한 파일(`WidgetCover.kt`)에만** 허용한다. `WidgetNoBitmapTest`는 그 파일만 예외로 두고 나머지는 그대로 막는다.
- 예산을 시험으로 지킨다: 비트맵 한 장 `폭×높이×4바이트 ≤ 200KB`(≈ 160×300px 이하), 위젯 하나당 6장 이하, 합계는 화면 폭×높이×4×1.5 한도의 1/10 이하.
- 한도를 넘거나 디코딩에 실패하면 표지를 그리지 않고 제목 타일로 그린다(위젯이 죽지 않는다).

### 3.5 설정 화면
- 보기를 고르고 테마·투명도·글자 크기를 정한다(표 위젯과 같은 화면). 표지·진행은 자동이다.

## 4. 단계 (각 단계마다 시험·실기기 확인·승인)
- **M5a (읽기)**: 3.1~3.5. 표지·진행 막대 표시, 표지 탭 → 노션 페이지.
- **M5b (쓰기)**: 표지 아래 양쪽 모서리의 `−`/`+`로 읽은 쪽(`ing`)을 10쪽씩 바꾼다. M3의 `view_writes` 큐(`ViewWriter.addPages`)를 쓰고 노션을 직접 부르지 않는다. 노션 데이터를 바꾸므로 실기기 확인은 되돌릴 수 있게 한다(+10 확인 뒤 −10으로 복원).
  - 읽은 쪽·전체 쪽은 보기에서 숨겨져 있으므로 동기화가 스키마에서 `ing`·`page` 이름 규칙으로 찾아 `ViewColumn.role`을 달아 쓰기 정보(`columnInfo`)에 넣는다(보이는 열 목록에는 넣지 않아 표 위젯에는 영향이 없다). 값은 `view_rows.typed`에 둔다.
  - 0 아래로 가지 않고 전체 쪽을 넘지 않는다(이미 넘은 값은 +가 깎지 않는다). 막대는 읽은 쪽÷전체 쪽으로 바로 다시 그린다(노션 수식과 같다고 보는 근사, 다음 동기화가 맞춘다).
  - 버튼은 표지 폭이 72dp 이상일 때만, 보이는 면 28dp(밀도 우선, 눌림 48dp 미만), 테마와 무관한 반투명 검정 면 + 흰 아이콘(낮은 투명도·밝은 표지에서도 보이게). 표지가 없는 책은 제목을 버튼 위 칸에 둔다.
  - 한계: 노션에서 읽은 쪽을 고친 뒤 동기화되기 전에 위젯에서 누르면 낡은 값에 더한 값이 노션을 덮는다(M3 숫자 쓰기와 같은 규칙). 한 번에 바뀌는 쪽 수(10)는 설정 없이 고정이다.

## 5. 시험·검증
- 단위: 파일 속성 읽기(외부/업로드/없음), 진행 계산(0~1, %, ing/page, 0쪽·전체 0쪽), `CoverDownloader`(MockWebServer: 토큰 헤더 없음, 상한 초과·리다이렉트·비이미지 거부), `CoverStore` 정리, 예산 시험, Glance 위젯 시험(표지 있음/없음/실패, 책 0·1·2·6권), RemoteViews 변환(자식 10개·View 수), Room v14→v15 마이그레이션.
- 실기기(Galaxy S25): 표지가 나오는지, 글꼴·다크·라이트, 메모리·StrictMode 0줄(`NotionCalStrictMode`), 오프라인에서 마지막 표지 유지.

## 6. 위험과 한계
- 서점·외부 이미지 서버를 기기가 직접 부른다(새 외부 호출). 사용자 노션 데이터가 가리키는 주소만 부르고 쿠키·토큰은 보내지 않는다.
- 표지 저작권: 개인 기기 안 캐시이며 앱 밖으로 내보내지 않는다.
- 노션 업로드 표지는 만료 주소라 동기화가 오래 끊기면 새 표지를 못 받는다(받아 둔 파일은 계속 보인다).
- 시험용 표본 표지는 직접 그린 단색 이미지를 쓴다(실제 책 표지를 저장소에 넣지 않는다).
